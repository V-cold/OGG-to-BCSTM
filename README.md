# OGG-to-BCSTM
A stand alone of a script I wrote to unpack an OGG to a WAV then convert it to a BCSTM file.

##Usage 
In your libraries while coding, "import convert_ogg from BCSTMCreationProtocol.py"
call "convert_ogg(ogg_path,out_path)" to convert an ogg file to a BCSTM file.
ogg_path is the location of your ogg file to convert.
out_path is the location you want to write your ogg file to.
